AHL 4.15 — Linear combinations of normal variables（正規分布にしたがう確率変数の一次結合）

ノートWhat you should be able to do
  • 独立な normal の和や差が、やはり normal になると言える。
  • その平均と分散を出して、\(N(\mu,\ \sigma^{2})\) の形に書ける。
  • そこから normCdf で確率を求められる。
  • \(\bar{X} \sim N\!\left(\mu,\ \dfrac{\sigma^{2}}{n}\right)\) を使い、標本平均の確率を求められる。
  • central limit theorem（中心極限定理）が何を言っているかを説明できる。
  • もとの分布が normal と分からないとき、標本数が十分に大きければ \(\bar{X}\) を近似的に normal として扱えると分かる。

AHL 4.14 では、独立な確率変数の和について、平均と分散を求めました。しかし、平均と分散だけでは、その確率変数がどのような分布にしたがうかまでは分かりません。

このページでは、もとの確率変数が normal distribution（正規分布）にしたがうとき、和・差・標本平均の分布まで求められることを学びます。

The idea

1. 平均と分散だけでは、確率は決まりません

AHL 4.14 で、独立な確率変数の和について

\[ E(X_1 + X_2) = E(X_1) + E(X_2), \qquad \text{Var}(X_1 + X_2) = \text{Var}(X_1) + \text{Var}(X_2) \]

を学びました。この \(2\) つは、どんな分布でも成り立ちます。

ただし、平均と分散だけでは、確率は一意に決まりません。 同じ平均・同じ分散をもつ分布は、いくらでもあるからです。確率を計算するには、normal など、分布の種類も分かっている必要があります。

たとえば \(X \sim N(250,\ 8^{2})\) を \(2\) つ足すと、\(X_1 + X_2\) の平均は \(500\)、分散は \(128\) です。この \(2\) つの数だけでは、\(P(X_1 + X_2 > 510)\) は決まりません。このページが足すのは、その分布の種類です。

linear combination（一次結合）とは

\(X + Y\)、\(2X - Y\)、\(\dfrac{X_1 + \cdots + X_n}{n}\) のように、確率変数に定数をかけて足し合わせたものを linear combination（一次結合）といいます。

「和」「差」「標本平均」は、すべて一次結合の例です。 ですからこのページの \(3\) つの話題は、どれも \(1\) つの考え方で扱えます。

重要独立な normal random variables の linear combination も normal distribution にしたがう

\(X_1,\ \ldots,\ X_n\) が互いに独立で、

\[ X_i \sim N(\mu_i,\ \sigma_i^{2}) \]

にしたがうとします。このとき

\[ Y = a_1X_1 + \cdots + a_nX_n \tag{1}\]

とおきます。ここで \(Y\) は、\(X_1,\ \ldots,\ X_n\) にそれぞれ定数 \(a_1,\ \ldots,\ a_n\) をかけて足し合わせて作った、新しい確率変数です。

この \(Y\) も normal distribution にしたがい、

\[ E(Y) = a_1\mu_1 + \cdots + a_n\mu_n \tag{2}\]

\[ \text{Var}(Y) = a_1^{2}\sigma_1^{2} + \cdots + a_n^{2}\sigma_n^{2} \tag{3}\]

となります。

平均では係数をそのまま使いますが、分散では係数を \(2\) 乗します。 引き算でも分散が足し算になるのは、この \(2\) 乗によって負の符号が消えるためです。

シラバスの書き方は、こうです。

A linear combination of \(n\) independent normal random variables is normally distributed. In particular, \(X \sim N(\mu,\ \sigma^{2}) \Rightarrow \bar{X} \sim N\!\left(\mu,\ \frac{\sigma^{2}}{n}\right)\).

「normal を入れれば、normal が出てくる」——これだけです。どんな分布でもこうなるわけではありません（独立な \(2\) つの Poisson の和が Poisson になるのは、AHL 4.17 の別の規則です）。

2. 分散を足して、最後に平方根をとります

独立な確率変数を足すときは、standard deviation（標準偏差）を直接足すのではなく、まず variance（分散）を足します。 最後に平方根を取って標準偏差へ戻します。

\(M \sim N(250,\ 8^{2})\) と \(S \sim N(180,\ 6^{2})\) が独立なとき、\(2\) つの値の合計を表す新しい確率変数 \(M + S\) を考えます。

平均（expected value）は、係数がどちらも \(1\) なので足すだけです。

\[ E(M + S) = 250 + 180 = 430 \]

次に、分散（variance）を求めます。\(M\) と \(S\) は独立なので、それぞれの分散を足します。

\[ \text{Var}(M + S) = 8^{2} + 6^{2} = 100 \]

標準偏差（standard deviation）は、分散の正の平方根です。

\[ \sigma_{M+S} = \sqrt{100} = 10 \]

したがって、\(M + S\) がしたがう分布（distribution）は

\[ M + S \sim N(430,\ 10^{2}) \]

です。ここで、\(E\) は平均、\(\text{Var}\) は分散、\(\sigma\) は標準偏差を表します。

\(N(\mu,\ \sigma^{2})\) のカッコの \(2\) 番目は、分散です。 \(10^{2} = 100\) なので \(N(430,\ 100)\) と書いても同じ分布ですが、標準偏差の \(10\) をそのまま書くのではありません。

図 1 のとおり、\(M\) と \(S\) を足して出てくるのも normal distribution です。

平均と分散の求め方は、すでに学習した AHL 4.14 の内容です。また、normal distribution を使った確率の計算は、SL 4.9 で学習した内容です。このページで新しく学ぶのは、それらをつなぐ部分、つまり「独立な normal random variables の linear combination も normal distribution にしたがう」という性質です。

3. \(3\) ステップの型

この項目の問題は、ほとんど同じ形をしています。

警告normCdf に入れるのは、標準偏差です

GDC の normCdf に入力するのは mean（平均）と standard deviation（標準偏差）です。分散を求めた後、平方根を取るのを忘れないでください。

\(M + S\) の例なら、\(E = 430\) → \(\text{Var} = 100\) → \(M + S \sim N(430,\ 100)\) と書いて、\(\sigma = 10\) を normCdf へ、という流れです。

\(1\) と \(2\) は AHL 4.14、\(3\) の後半は SL 4.9 です。 このページが新しく足しているのは、手順 \(3\) の前半、「normal だと言ってよい」という一歩だけです。

重要答案には、\(N(\mu,\ \sigma^{2})\) の行を必ず書いてください

電卓に入れる前に、求めた分布を \(1\) 行書く習慣をつけてください。

\(M + S \sim N(430,\ 100)\)

ここに点が付きます。そして、書いておくと \(\sigma\) と \(\sigma^{2}\) を取りちがえません。 \(N\) のカッコの \(2\) 番目は分散、normCdf に入れるのは標準偏差です。

4. 差のときは、平均は引いて、分散は足します

\(X\) と \(Y\) が独立であるとします。ここで

\[ D = X - Y \]

とおきます。\(D\) は、\(X\) の値から \(Y\) の値を引いて作る、差を表す新しい確率変数です。たとえば \(X\) が \(1\) 回目の測定値、\(Y\) が \(2\) 回目の測定値なら、\(D\) は「\(1\) 回目の測定値と \(2\) 回目の測定値の差」を表します。

\(D = X - Y\) は、\(Y\) の係数を \(-1\) とする linear combination（一次結合）として

\[ D = X + (-1)Y \]

と書けます。

平均（expected value）は、係数をそのまま使うので

\[ E(D) = E(X) - E(Y) \]

となります。一方、分散（variance）は係数を \(2\) 乗して使います。\(X\) と \(Y\) は独立なので

\[ \text{Var}(D) = \text{Var}(X) + (-1)^{2}\text{Var}(Y) = \text{Var}(X) + \text{Var}(Y) \tag{4}\]

となります。

したがって、差の平均は引き算ですが、差の分散は足し算です。 分散が足し算になるのは、係数 \(-1\) が \(2\) 乗されて \((-1)^{2} = 1\) となり、負の符号が消えるためです。この式は、\(X\) と \(Y\) が独立である場合に使えます（AHL 4.14）。

「\(A\) のほうが大きい確率」は、差で考えます

「\(A\) が \(B\) より大きい確率を求めなさい」（Find the probability that A is greater than B）と聞かれたときは、\(A\) と \(B\) の差を表す新しい確率変数

\[ D = A - B \]

を考えます。なぜ差を考えるのかというと、次の言いかえができるからです。

\[ A > B \iff A - B > 0 \iff D > 0 \]

\(A\) のほうが大きいという出来事と、\(D\) が正であるという出来事は、まったく同じものです。ですから、確率も

\[ P(A > B) = P(A - B > 0) = P(D > 0) \tag{5}\]

と書きかえられます。

\(A\) と \(B\) が独立な normal random variables なら、第1節より \(D = A - B\) も normal distribution にしたがいます。ですから、あとは \(1\) つの normal distribution の問題です。

  1. \(D\) の平均を求める … \(E(D) = E(A) - E(B)\)
  2. \(D\) の分散と標準偏差を求める … \(\text{Var}(D) = \text{Var}(A) + \text{Var}(B)\)、\(\sigma_D = \sqrt{\text{Var}(D)}\)
  3. normCdf で \(P(D > 0)\) を求める

\(A\) と \(B\) の \(2\) つの分布を直接見くらべるのではなく、「\(A - B\) は \(0\) より大きいか」という \(1\) つの normal distribution の問題に変える——これがこの型の考え方です。

5. sample mean（標本平均）\(\bar{X}\) の分布

シラバスが In particular と名指ししている、この項目のもう \(1\) つの中心です。

sample mean（標本平均）を \(\bar{X}\) と表します。\(\bar{X}\) は「エックス・バー」と読みます。

population（母集団）から、同じ条件で独立に \(n\) 個の値を取り出すとします。

\[ X_1,\ X_2,\ \ldots,\ X_n \]

は、\(1\) 回目、\(2\) 回目、……、\(n\) 回目の抽出で得られる値を表す random variables（確率変数）です。

たとえば身長を調べる場合、\(X_1\) は「\(1\) 人目としてランダムに選ばれる人の身長」です。選ぶ前は値が決まっていないので、\(X_1\) は \(1\) つの数値ではなく random variable であり、実際に測って得られた \(168\) cm などの値は \(X_1\) の observed value（観測値）です。

population が normal distribution \(N(\mu,\ \sigma^{2})\) にしたがうなら、各 \(X_i\) も同じ分布にしたがいます。

\[ X_i \sim N(\mu,\ \sigma^{2}) \]

この \(n\) 個の値の平均を表す新しい確率変数が、sample mean \(\bar{X}\) です。

\[ \bar{X} = \frac{X_1 + \cdots + X_n}{n} = \frac{1}{n}X_1 + \cdots + \frac{1}{n}X_n \]

したがって、\(\bar{X}\) は各 \(X_i\) の係数が \(\dfrac{1}{n}\) である linear combination（一次結合）です。

\(\bar{X}\) の平均（mean）は

\[ \begin{aligned} E(\bar{X}) &= \frac{1}{n}\mu + \cdots + \frac{1}{n}\mu \\ &= n\left(\frac{1}{n}\right)\mu \\ &= \mu \end{aligned} \]

となります。つまり、sample mean \(\bar{X}\) の平均は、population mean（母平均）\(\mu\) と同じです。

次に、分散（variance）では係数を \(2\) 乗します。各 \(X_i\) は独立で、分散はすべて \(\sigma^{2}\) なので

\[ \begin{aligned} \text{Var}(\bar{X}) &= \left(\frac{1}{n}\right)^{2}\text{Var}(X_1) + \cdots + \left(\frac{1}{n}\right)^{2}\text{Var}(X_n) \\ &= \left(\frac{1}{n}\right)^{2}\sigma^{2} + \cdots + \left(\frac{1}{n}\right)^{2}\sigma^{2} \\ &= n\left(\frac{1}{n}\right)^{2}\sigma^{2} \\ &= n \cdot \frac{1}{n^{2}}\sigma^{2} \\ &= \frac{\sigma^{2}}{n} \end{aligned} \]

となります。ここで大事なのは、分散では係数 \(\dfrac{1}{n}\) を \(2\) 乗することです。 ですから分散は \(\dfrac{1}{n}\) 倍ではなく

\[ \boxed{\ \text{Var}(\bar{X}) = \frac{\sigma^{2}}{n}\ } \]

です。したがって、\(\bar{X}\) の標準偏差（standard deviation）は

\[ \sigma_{\bar{X}} = \sqrt{\frac{\sigma^{2}}{n}} = \frac{\sigma}{\sqrt{n}} \tag{6}\]

となります。

また、独立な normal random variables の linear combination も normal distribution にしたがうため

\[ \boxed{\ \bar{X} \sim N\!\left(\mu,\ \frac{\sigma^{2}}{n}\right)\ } \tag{7}\]

となります。

\(\bar{X}\) の標準偏差 \(\dfrac{\sigma}{\sqrt{n}}\) を standard error（標準誤差）といいます。\(n\) が大きいほど standard error は小さくなり、\(\bar{X}\) は population mean \(\mu\) の近くに集まりやすくなります。これは、\(\bar{X}\) の分布の「広がり」についての性質です。

一方、次に学ぶ central limit theorem（中心極限定理）は、\(n\) が大きくなると \(\bar{X}\) の分布の「形」が normal distribution に近づくことを説明します。

中心は動かず、幅だけが狭くなります

図 2 を見てください。\(4\) つの曲線は、すべて \(\mu = 1000\) を中心にしています。違うのは幅だけです。

標本の数が増えると、偶然によるばらつきが平均の中で打ち消し合うため、\(\bar{X}\) は母平均 \(\mu\) の近くに集まりやすくなります（AHL 4.14）。

\(\sigma / n\) ではありません。 分散が \(\sigma^{2}/n\) なので、平方根をとると分母は \(\sqrt{n}\) になります。

\(\sigma = 12\)、\(n = 9\) なら \(\sigma_{\bar{X}} = \dfrac{12}{3} = 4\) です。\(\dfrac{12}{9}\) ではありません。

ノート意味は「平均のほうが、当てにできる」ということです

\(1\) 袋の質量は \(1000\) g から \(20\) g ずれることもあります。しかし \(9\) 袋の平均が \(20\) g もずれることは、めったにありません。重い袋と軽い袋が打ち消し合うからです。

これが、標本をたくさんとる理由です。

警告\(\bar{X}\) と、\(1\) つの \(X\) を取りちがえないでください

問題文が

  • the mass of one bag … \(X \sim N(1000,\ 12^{2})\)、\(\sigma = 12\)
  • the mean mass of nine bags … \(\bar{X} \sim N(1000,\ 16)\)、\(\sigma = 4\)
  • the total mass of nine bags … \(\sum X \sim N(9000,\ 1296)\)、\(\sigma = 36\)

の \(3\) つを区別します。\(\sigma\) は \(12\)、\(4\)、\(36\) と全部違います。 平均のほうは、one と mean が同じ \(1000\) で、total だけ \(9000\) です。

平均が同じでも \(\sigma\) が違う——one と mean の取りちがえが危ないのは、まさにここです。

one なのか mean なのか total なのか——そこを丸で囲んでから計算を始めてください。

6. Central limit theorem（中心極限定理）

これまでは、population（母集団）が normal distribution にしたがう場合を考えてきました。

しかし、実際のデータの分布は、いつも normal になるとはかぎりません。たとえば待ち時間の分布は、短い値が多く、右側に長く伸びた形になることがあります。

では、もとの分布が normal でない場合、sample mean \(\bar{X}\) はどのような分布になるのでしょうか。

\(1\) 回の測定値と sample mean は、別のものです

同じ population から独立に取り出した \(n\) 個の値を

\[ X_1,\ X_2,\ \ldots,\ X_n \]

とします。\(X_i\) は、\(i\) 回目の抽出で得られる値を表す random variable（確率変数）です。その sample mean は

\[ \bar{X} = \frac{X_1 + \cdots + X_n}{n} \]

です。

もとの population が normal でなければ、\(1\) 回の測定値 \(X_i\) の分布も normal ではありません。しかし、\(n\) 個の値から作った sample mean \(\bar{X}\) の分布は、\(n\) が大きくなるにつれて normal distribution に近づいていきます。

図 3 のいちばん左は、normal ではない population です。右に大きく尾を引いています。その右の \(3\) つは、そこから \(n\) 個を取り出して平均する、ということをくり返して描いた \(\bar{X}\) の分布です。

  • \(n = 2\) … まだ歪んでいます
  • \(n = 10\) … かなり normal に近づいてきました
  • \(n = 40\) … 赤い normal の曲線にほぼ重なっています

これが central limit theorem（中心極限定理、CLT）です。

同じ population から独立に取り出した標本の sample mean \(\bar{X}\) は、sample size \(n\) が十分に大きいとき、もとの population が normal でなくても、approximately normal distribution（近似的な正規分布）にしたがいます。

population の平均を \(\mu\)、分散を \(\sigma^{2}\) とすると

\[ \boxed{\ \bar{X} \approx N\!\left(\mu,\ \frac{\sigma^{2}}{n}\right)\ } \tag{8}\]

となります。したがって、\(\bar{X}\) の平均、分散、標準偏差は

\[ E(\bar{X}) = \mu \]

\[ \text{Var}(\bar{X}) = \frac{\sigma^{2}}{n} \]

\[ \sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}} \]

です。この \(\dfrac{\sigma}{\sqrt{n}}\) が、第5節で出てきた standard error（標準誤差）です。

平均と分散は、もとが normal でなくてもそのままです（AHL 4.14 から出るので、分布の形は関係ありません）。CLT が足してくれるのは、形が normal に近いという一点だけです。

\(n\) が大きくなると、何が起こるのか

\(n\) が大きくなると

\[ \frac{\sigma}{\sqrt{n}} \]

は小さくなります。そのため、sample mean \(\bar{X}\) は population mean \(\mu\) の近くに集まりやすくなります。また、\(\bar{X}\) の分布の形は、しだいに normal distribution に近づきます。

CLT は「データが normal になる」とは言っていません

ここを取りちがえる答案がよくあります。

CLT は、もとのデータ \(X_i\) の分布が normal になるという定理ではありません。 normal に近づくのは、何度も標本を取って作った sample mean \(\bar{X}\) の分布です。

図 3 のいちばん左の形は、\(n\) をどれだけ大きくしても変わりません。変わるのは、その右の \(3\) つのほうです。

どのくらいの \(n\) が必要ですか

シラバスは、こう書いています。

In general, \(\bar{X}\) approaches normality for large \(n\), how large depends upon the distribution from which the sample is taken. In examinations, \(n > 30\) will be considered sufficient.

試験では、通常

\[ n > 30 \]

を「十分に大きい」とする目安が使われます。ただし、これは数学的な境界ではありません。 実際に必要な sample size は、もとの分布の形によって変わります。分布の偏りが強い場合や外れ値が多い場合は、より大きな \(n\) が必要になることがあります。

重要答案での書き方

CLT を使うときは、normal distribution で近似している理由を \(1\) 行書きます。

試験ではこう書く

Since \(n = 40 > 30\), by the central limit theorem, \(\bar{X}\) is approximately normal.

（\(n = 40 > 30\) なので、中心極限定理により \(\bar{X}\) は近似的に正規分布にしたがう、という意味です。）

ここでは、approximately（近似的に）と書くことが大事です。もとの population が normal だと分かっている場合を除き、exactly normal とは言えません。

7. 平均で解いても、合計で解いても同じです

\(40\) 人の待ち時間を調べます。\(i\) 人目の待ち時間を \(X_i\) とし、\(1\) 人あたりの待ち時間について

\[ \mu = 4.2, \qquad \sigma = 2.5 \]

とします。\(1\) 人分の待ち時間が normal distribution にしたがうとは分かっていません。ここでは、次の確率を求めます。

\(40\) 人の平均待ち時間が \(4.5\) 分を超える確率

方法1：平均で考える

\(40\) 人の sample mean を

\[ \bar{X} = \frac{X_1 + \cdots + X_{40}}{40} \]

とします。\(n = 40 > 30\) なので、CLT により

\[ \bar{X} \approx N\!\left(4.2,\ \frac{2.5^{2}}{40}\right) = N(4.2,\ 0.15625) \]

です。したがって、求める確率は \(P(\bar{X} > 4.5)\) です。

方法2：合計で考える

\(40\) 人の合計待ち時間を表す新しい確率変数を

\[ T = X_1 + \cdots + X_{40} \]

とします（\(\sum X_i\) と書くこともあります）。合計 \(T\) の平均は

\[ E(T) = 40 \times 4.2 = 168 \]

です。各 \(X_i\) は独立なので、合計の分散は

\[ \text{Var}(T) = 40 \times 2.5^{2} = 250 \]

となります。また、\(T = 40\bar{X}\) なので、\(\bar{X}\) が approximately normal なら \(T\) も approximately normal です。

\[ T \approx N(168,\ 250) \]

この方法では、\(40\) 人の合計が \(40 \times 4.5 = 180\) 分を超える確率 \(P(T > 180)\) を求めます。

なぜ \(2\) つの確率は同じなのか

\(T = 40\bar{X}\) なので

\[ \begin{aligned} \bar{X} > 4.5 &\iff 40\bar{X} > 40 \times 4.5 \\ &\iff T > 180 \end{aligned} \tag{9}\]

です。つまり、「平均待ち時間が \(4.5\) 分を超える」ことと「合計待ち時間が \(180\) 分を超える」ことは、同じ出来事です。したがって

\[ \boxed{\ P(\bar{X} > 4.5) = P(T > 180)\ } \]

となります。

平均と合計では数値の尺度が違いますが、表している出来事は同じです。ですから、どちらの分布を使っても同じ確率が得られます。

問題が平均について聞いているなら平均を使い、合計について聞いているなら合計を使うのが自然です。わざわざ一方から他方へ変換する必要はありません。

8. exactly normal と approximately normal

sample mean \(\bar{X}\) が exactly normal になるか approximately normal になるかは、population の分布によって決まります。

population が normal の場合

各 \(X_i\) が独立で

\[ X_i \sim N(\mu,\ \sigma^{2}) \]

なら、独立な normal random variables の linear combination も normal なので

\[ \boxed{\ \bar{X} \sim N\!\left(\mu,\ \frac{\sigma^{2}}{n}\right)\ } \]

です。この場合、\(\bar{X}\) は exactly normal（正確に正規分布）です。\(n\) が小さくても構いません。 \(X \sim N(1000,\ 12^{2})\) から \(n = 4\) の標本をとるなら、\(4 < 30\) でも \(\bar{X}\) は exactly normal で、CLT は要りません。

population が normal とは限らない場合

もとの population が normal でなくても、\(n\) が十分に大きければ、CLT により

\[ \boxed{\ \bar{X} \approx N\!\left(\mu,\ \frac{\sigma^{2}}{n}\right)\ } \]

として扱えます。この場合は approximately normal（近似的に正規分布）です。

最後に確認

どちらの場合でも、\(\bar{X}\) の平均と分散は

\[ E(\bar{X}) = \mu, \qquad \text{Var}(\bar{X}) = \frac{\sigma^{2}}{n} \]

です。違うのは分布の形についてで、

  • population が normal なら、\(\bar{X}\) は exactly normal
  • population が normal とは限らなければ、十分に大きな \(n\) に対して approximately normal

となります。そして、\(n\) が小さく、もとの分布も normal と分からない場合は、normal と仮定しません。normal approximation（正規近似）を正当化できないからです。

なお、CLT は平均と合計についての定理です。もとが normal でないとき、\(n\) をどれだけ大きくしても、CLT が \(1\) つの値 \(X\) を normal にしてくれることはありません（上）。

警告「分布が不明」と「normal ではない」は違います

問題文に「この分布は正規分布ではない」と書いてあれば、normal ではないと分かっています。一方、平均と標準偏差だけが与えられている場合は、分布が不明なだけです。normal かもしれませんし、そうでないかもしれません。

上の判断はどちらの場合も同じように使えます。ただし答案では、問題文に書かれていること以上を断定しないでください。

Why it works

ノートクリックすると開きます

ここで説明するのは \(2\) つです。なぜ \(\bar{X}\) の分散が \(\dfrac{\sigma^{2}}{n}\) になるのかと、CLT がなぜ起きるのか。

\(\bar{X}\) の分散は、4.14 から出ます

\(\bar{X}\) は、\(n\) 個を足して \(n\) で割ったものです。

\[ \bar{X} = \frac{1}{n}\bigl(X_1 + X_2 + \cdots + X_n\bigr) \]

まず、カッコの中の分散を出します。独立なので、AHL 4.14 から

\[ \text{Var}(X_1 + \cdots + X_n) = \underbrace{\sigma^{2} + \sigma^{2} + \cdots + \sigma^{2}}_{n \text{ 個}} = n\sigma^{2} \]

次に、\(\dfrac{1}{n}\) を掛けます。\(\text{Var}(aX) = a^{2}\text{Var}(X)\) なので

\[ \text{Var}(\bar{X}) = \left(\frac{1}{n}\right)^{2} \times n\sigma^{2} = \frac{n\sigma^{2}}{n^{2}} = \frac{\sigma^{2}}{n} \]

\(\dfrac{1}{n^{2}}\) を掛けて、\(n\sigma^{2}\) が入ってくる。 その差し引きで \(\dfrac{\sigma^{2}}{n}\) が残ります。

平均のほうは、\(E(\bar{X}) = \dfrac{1}{n} \times n\mu = \mu\) で、\(n\) によらず \(\mu\) のままです。だから 図 2 で中心が動かないのです。

CLT は、打ち消し合いの結果です

証明は、この課程の範囲を大きく超えます。ただ、なぜそうなるのかの見当はつけられます。

\(\bar{X}\) を作るとき、\(n\) 個の値を足しています。歪んだ分布から \(1\) 個とれば、その値も歪んだ出方をします。しかし \(40\) 個とって足すと、大きく外れた値は、ふつうの値に埋もれていきます。

図 3 の左の分布では、たまに \(4\) や \(5\) が出ます。\(n = 1\) ならそれがそのまま出ますが、\(n = 40\) の平均では、\(1\) 個の \(5\) は \(\dfrac{5}{40}\) ぶんしか効きません。\(1\) 個の極端な値では、平均を動かせなくなるのです。

その結果、\(\bar{X}\) は「たくさんの小さなずれが積み重なったもの」になります。そういうものの分布は、平均と標準偏差がきちんと決まる分布からとったかぎり、\(n\) が大きくなるにつれて正規分布に近づいていきます——これが中心極限定理の内容です。

例題 1 In a school canteen, the mass of a main dish, in grams, is \(M \sim N(250,\ 8^{2})\) and the mass of a side dish is \(S \sim N(180,\ 6^{2})\). The two masses are independent.

A meal consists of one main dish and one side dish. Let \(T = M + S\) be the total mass of a meal.

(a) State the distribution of \(T\), giving its mean and variance.

(b) Find \(P(T > 445)\).

(c) Find the probability that the total mass of a meal is between \(420\) g and \(445\) g.

日本語訳

ある学校の食堂で、主菜の質量（グラム）は \(M \sim N(250,\ 8^{2})\)、副菜の質量は \(S \sim N(180,\ 6^{2})\) です。この \(2\) つの質量は独立です。

\(1\) 食は、主菜 \(1\) つと副菜 \(1\) つからなります。\(1\) 食の合計質量を \(T = M + S\) とします。

(a) \(T\) の分布を、平均と分散を示して述べなさい。

(b) \(P(T > 445)\) を求めなさい。

(c) \(1\) 食の合計質量が \(420\) g から \(445\) g のあいだになる確率を求めなさい。

(a) 第3節の \(3\) ステップのうち、\(1\) と \(2\) です。\(1\) 食の合計質量を \(T = M + S\) とおきます。

平均は、係数をそのまま使います。

\[ E(T) = 250 + 180 = 430 \]

分散は、係数を \(2\) 乗して足します。ここでは係数がどちらも \(1\) なので、\(8^{2}\) と \(6^{2}\) をそのまま足します。standard deviation ではなく、variance を足すところが要点です。

\[ \text{Var}(T) = 8^{2} + 6^{2} = 64 + 36 = 100 \]

\(M\) も \(S\) も normal で、独立なので、\(T\) は exactly normal です（第1節）。

\[ T \sim N(430,\ 100) \]

検算。 \(\sigma = \sqrt{100} = 10\) です。\(8 + 6 = 14\) ではありません（第2節）。

(b) \(\sigma = 10\) を normCdf に入れます。\(100\) ではありません。

normCdf(445, ∞, 430, 10)

\[ P(T > 445) = 0.0668 \]

\(1\) 食の合計質量が \(445\) g を超えるのは、およそ \(100\) 食のうち \(7\) 食です。

(c) 両端があるので、normCdf の \(2\) か所を埋めるだけです。

normCdf(420, 445, 430, 10)

\[ P(420 < T < 445) = 0.775 \]

\(1\) 食のおよそ \(77\%\) が、\(420\) g から \(445\) g のあいだに入ります。

ノート解答例（答案用紙にはこう書く）

(a) \[ E(T) = 250 + 180 = 430 \] \[ \text{Var}(T) = 8^{2} + 6^{2} = 100 \] \[ T \sim N(430,\ 100) \]

(b) \[ P(T > 445) = 0.0668 \]

(c) \[ P(420 < T < 445) = 0.775 \]

例題 2 The lifetime of a battery of brand A, in hours, is \(X \sim N(30,\ 4^{2})\). The lifetime of a battery of brand B is \(Y \sim N(27,\ 3^{2})\). All lifetimes are independent.

One battery of each brand is chosen at random. Let \(D = X - Y\).

(a) State the distribution of \(D\).

(b) Find the probability that the brand A battery lasts longer than the brand B battery.

(c) Find the probability that the brand A battery lasts at least \(5\) hours longer than the brand B battery.

(d) Explain why the standard deviation of \(D\) is not \(4 - 3 = 1\).

日本語訳

ブランド A の電池の寿命（時間）は \(X \sim N(30,\ 4^{2})\)、ブランド B の電池の寿命は \(Y \sim N(27,\ 3^{2})\) です。すべての寿命は独立です。

lifetime は「寿命」、at least は「少なくとも」という意味です。

各ブランドから電池を \(1\) 個ずつ無作為に選びます。\(D = X - Y\) とします。

(a) \(D\) の分布を述べなさい。

(b) ブランド A の電池のほうが、ブランド B の電池より長持ちする確率を求めなさい。

(c) ブランド A の電池が、ブランド B の電池より少なくとも \(5\) 時間長持ちする確率を求めなさい。

(d) \(D\) の標準偏差が \(4 - 3 = 1\) にならない理由を説明しなさい。

(a) \(D = X - Y = X + (-1)Y\) とおきます。平均は係数をそのまま使い、分散は係数を \(2\) 乗します（式 4）。

\[ E(D) = 30 - 27 = 3 \]

\[ \text{Var}(D) = 4^{2} + (-1)^{2} \times 3^{2} = 16 + 9 = 25 \]

\(X\) も \(Y\) も normal で、独立なので、\(D\) は exactly normal です。

\[ D \sim N(3,\ 25) \]

\(N(3,\ 25)\) の \(25\) は分散なので、標準偏差は \(\sigma = \sqrt{25} = 5\) です。normCdf には \(5\) を入れます。

(b) 「A のほうが長い」は「\(D\) が正」ということです（式 5）。

\[ P(X > Y) = P(D > 0) \]

normCdf(0, ∞, 3, 5)

\[ P(D > 0) = 0.726 \]

ブランド A のほうが長持ちするのは、およそ \(73\%\) です。

検算。 \(E(D) = 3 > 0\) なので、確率は \(0.5\) より大きくなるはずです ✓

(c) at least 5 hours longer は \(D \geq 5\) です。

normCdf(5, ∞, 3, 5)

\[ P(D \geq 5) = 0.345 \]

\(5\) 時間以上長持ちするのは、およそ \(34\%\) です。

(d) 足すのは標準偏差ではなく分散で、しかも差のときも足します。\(Y\) の係数 \(-1\) が \(2\) 乗されて \(+1\) になるからです。\(Y\) を引いても \(Y\) のばらつきは消えず、\(Y\) がぶれれば \(X - Y\) もぶれるので、\(2\) つのばらつきは打ち消し合わずに重なります。

Variances add, not standard deviations, and they add for a difference as well: \(\text{Var}(D) = 4^{2} + (-1)^{2} \times 3^{2} = 25\), so the standard deviation is \(\sqrt{25} = 5\). Subtracting \(Y\) does not remove the variability of \(Y\).

(a) \[ E(D) = 30 - 27 = 3, \qquad \text{Var}(D) = 4^{2} + (-1)^{2} \times 3^{2} = 25 \] \[ D \sim N(3,\ 25) \]

(b) \[ P(X > Y) = P(D > 0) = 0.726 \]

Common errors

警告標準偏差を直接足してしまう

誤り：\(\sigma_{M+S} = 8 + 6 = 14\)

足せるのは variance（分散）であって、standard deviation（標準偏差）ではありません（第2節）。

正しくは：\(\text{Var}(M+S) = 8^{2} + 6^{2} = 100\)、\(\sigma = \sqrt{100} = 10\)。

警告差を取るときに、分散まで引いてしまう

誤り：\(\text{Var}(X - Y) = 4^{2} - 3^{2} = 7\)

\(Y\) の係数 \(-1\) は \(2\) 乗されて \(+1\) になるので、独立なら分散は足されます（第4節）。

正しくは：\(\text{Var}(X - Y) = 4^{2} + (-1)^{2} \times 3^{2} = 25\)、\(\sigma = 5\)。

警告\(N(\mu,\ \sigma^{2})\) と、GDC の標準偏差を混同する

誤り：normCdf(445, ∞, 430, 100)

\(N(430,\ 100)\) の \(100\) は分散で、normCdf に入れるのは標準偏差です（GDC 第1節）。

正しくは：normCdf(445, ∞, 430, 10)。分散を入れると \(0.440\) となり、正しい \(0.0668\) とはまったく違う答えになります。

警告exactly normal と、CLT による approximately normal を混同する

誤り：もとが normal なのに「\(n > 30\) でないので normal として扱えない」／ CLT を使ったのに「\(\bar{X}\) は normal である」と書く

もとが normal なら \(n\) によらず exactly normal、CLT から言えるのは approximately normal です（第8節）。

正しくは：Since \(X\) is normal, \(\bar{X}\) is exactly normal for any \(n\). ／ Since \(n = 40 > 30\), by the central limit theorem \(\bar{X}\) is approximately normal.

5 The random variable \(X\) is normally distributed with standard deviation \(\sigma\). A random sample of \(n\) observations is taken. Explain why the standard deviation of the sample mean is \(\dfrac{\sigma}{\sqrt{n}}\) and not \(\dfrac{\sigma}{n}\).

日本語訳

ノート解答例（答案用紙に書くこと）

\[ \bar{X} = \frac{1}{n}(X_1 + \cdots + X_n) \] \[ \text{Var}(X_1 + \cdots + X_n) = n\sigma^{2} \] \[ \text{Var}(\bar{X}) = \left(\frac{1}{n}\right)^{2} \times n\sigma^{2} = \frac{\sigma^{2}}{n} \] \[ \text{sd}(\bar{X}) = \sqrt{\frac{\sigma^{2}}{n}} = \frac{\sigma}{\sqrt{n}} \]

The formula \(\text{Var}(aX) = a^{2}\text{Var}(X)\) squares the factor \(\frac{1}{n}\), and the \(n\) independent variances add to \(n\sigma^{2}\). Taking the square root at the end gives \(\sqrt{n}\) in the denominator, not \(n\).

ヒント解説

Explain why なので、式を並べて、言葉で締めます。

要点は \(2\) つです。

  • \(\dfrac{1}{n}\) は \(2\) 乗されて \(\dfrac{1}{n^{2}}\) になる（AHL 4.14）
  • \(n\) 個の分散が足されて \(n\sigma^{2}\) になる（AHL 4.14）

\(\dfrac{n\sigma^{2}}{n^{2}} = \dfrac{\sigma^{2}}{n}\) で、\(n\) が \(1\) つ約分されて残ります。

最後に平方根をとるので、分母は \(\sqrt{n}\) です（途中式は「Why it works」を開くと出てきます）。

試験ではこう書く

Since \(\bar{X} = \frac{1}{n}(X_1 + \cdots + X_n)\) and the observations are independent, the variances add to give \(n\sigma^{2}\). Multiplying by \(\frac{1}{n}\) multiplies the variance by \(\left(\frac{1}{n}\right)^{2}\), so \(\text{Var}(\bar{X}) = \frac{n\sigma^{2}}{n^{2}} = \frac{\sigma^{2}}{n}\). The standard deviation is the square root of this, which is \(\frac{\sigma}{\sqrt{n}}\).

ある大人の体重（kg）は、平均 \(72\)、標準偏差 \(10\) の正規分布にしたがいます。あるエレベーターの最大積載量は \(620\) kg です。

lift は「エレベーター」、maximum load は「最大積載量」という意味です。

(a) \(8\) 人の大人がエレベーターに乗ります。合計体重が最大積載量を超える確率を求めなさい。

(b) ある生徒が、\(X \sim N(72,\ 10^{2})\) として答えを \(P(8X > 620)\) で計算しました。これが正しくない理由を説明しなさい。

ノート解答例（答案用紙に書くこと）

(a) \[ X_1 + \cdots + X_8 \sim N(8 \times 72,\ 8 \times 100) = N(576,\ 800) \] \[ \sigma = \sqrt{800} = 28.3 \] \[ P(\text{total} > 620) = 0.0599 \]

(b) \(8X\) represents one adult whose mass is multiplied by \(8\), not eight different adults. It gives \(\text{Var}(8X) = 8^{2} \times 100 = 6400\) and \(\sigma = 80\), whereas eight independent adults give \(\text{Var} = 8 \times 100 = 800\) and \(\sigma = 28.3\). With eight separate adults a heavy person can be offset by a lighter one, so the total varies much less.

試験ではこう書く

\(8X\) models a single adult whose mass is multiplied by \(8\), not eight different adults. Its variance is \(8^{2} \times 100 = 6400\), giving \(\sigma = 80\), whereas eight independent adults give \(\text{Var} = 8 \times 100 = 800\) and \(\sigma = 28.3\). Because the eight adults are separate, a heavy person can be offset by a lighter one, so the total mass is much less variable than \(8X\) suggests.
